Program Curriculum

Build real projects through hands-on engineering.

01

Core Java Fundamentals

▼
  • Java from ScratchVariables, data types, operators, control flow, loops, and writing clean, readable Java code from day one
  • Object-Oriented ProgrammingClasses, objects, inheritance, polymorphism, abstraction, encapsulation — the pillars of Java
  • Exception Handling & I/OTry-catch-finally, custom exceptions, file reading/writing, and handling real-world error scenarios
  • Collections FrameworkArrayList, HashMap, HashSet, LinkedList, iterators — mastering Java's built-in data structures
  • Generics & Functional JavaGeneric types, lambda expressions, streams API, and writing modern, concise Java code
02

Data Structures & Algorithms

▼
  • Arrays & StringsTwo-pointer technique, sliding window, string manipulation — building problem-solving intuition
  • Linked Lists & Stacks/QueuesSingly/doubly linked lists, stack operations, queue implementations, and real-world use cases
  • Trees & GraphsBinary trees, BST, BFS, DFS, graph representations — understanding hierarchical and networked data
  • Sorting & SearchingMerge sort, quick sort, binary search, time complexity analysis — writing efficient code that scales
  • Dynamic Programming & RecursionMemoization, tabulation, classic DP problems — developing algorithmic thinking
03

Git, GitHub & Open Source Foundations

▼
  • Version Control with Gitinit, add, commit, push, pull, branching, merging — collaborating on projects using Git
  • GitHub WorkflowForking, cloning, pull requests, code reviews, issues — the complete open-source contribution workflow
  • Understanding Open SourceLicenses, community etiquette, finding beginner-friendly projects, reading codebases
  • Your First ContributionFinding good first issues, writing meaningful PRs, engaging with maintainers, and getting merged
04

Spring Boot & Backend Development

▼
  • Spring Boot BasicsSetting up projects with Spring Initializr, dependency injection, annotations, and application architecture
  • REST APIsBuilding RESTful endpoints, request/response handling, validation, error handling — creating production-ready APIs
  • Database IntegrationSpring Data JPA, Hibernate, connecting to MySQL/PostgreSQL, writing queries, and managing data persistence
  • Testing & DeploymentUnit testing with JUnit, integration tests, building JARs, and deploying your Spring Boot application
05

Real-World Open Source Projects

▼
  • Contributing to Java OSSFinding and contributing to real Java open-source projects on GitHub — Apache, Spring, Eclipse ecosystem
  • Building Your Own ProjectDesigning, building, and open-sourcing your own Java project — from idea to published repository
  • Code Quality & Best PracticesClean code principles, SOLID, design patterns, code reviews, and writing maintainable software
  • Portfolio & Career ShowcaseDocumenting your contributions, writing technical blog posts, and presenting your work to peers
